# Dataset notes

One file per subject or per acquisition, recording what was observed in that
recording: stream layout, channel mapping, lead geometry, montage quirks, and
anything that had to be established by hand.

These are notes, not contract. Nothing here defines how the app behaves. If an
observation should change behavior, it becomes a manifest row, a config value, or
a guardrail, and the reason is recorded in `docs/decisions.md`.
